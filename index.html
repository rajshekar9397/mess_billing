⚙ Setup — Connect to Google Sheets

📋 Step-by-Step Setup (one time only)

This connects your app to Google Sheets so all devices share the same data.

  1. Open script.google.com → click New Project
  2. Delete any existing code. Paste the entire contents of Code.gs file
  3. Click Deploy → New Deployment
  4. Type: Web App · Execute as: Me · Access: Anyone
  5. Click Deploy → Copy the Web App URL
  6. Paste that URL below and click Save & Test Connection

How Mixed Meals Work

On any day, each company can have multiple meal types. For example:
• 9th April (Wednesday = Chicken day) — MediJourn asked for 15 Chicken + 2 Egg
• Wadi Surgicals had 10 Veg + 2 Chicken on the same day

In Daily Entry, each company card has a "+ Add another meal type" button. The monthly report automatically groups all Egg days together, all Veg days together, and all Chicken days together for clean billing.
